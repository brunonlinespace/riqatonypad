# RiqatonyPad 1.1.2

Current release: RiqatonyPad 2.0.0-x16.5 — Riqa Icons Harmony, Humility, Heritage and Halcyon.

This release removes retired command-icon filenames outside the supplied light/dark packs and wires the App Drag-and-Drop, Editor Layout, Ribbon and Retro selectors to their dedicated icons.

RiqatonyPad is a standalone Rich Text Format editor.

**1.1.2 is the RiqatonyPad identity migration from Ricopad 1.0.15.** The original App Drag-and-Drop icon synchronization and all existing RTF, file-safety, Ribbon, and editor behaviors are retained. This release changes public identity, independent configuration paths, documentation, application artwork and packaging identity only; it does not restructure the editor or codec.
